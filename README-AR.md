# معاينة Weezy

1. فك الضغط عن مجلد Demo كاملًا.
2. افتح Open-demo.html بالضغط مرتين، أو START-DEMO.cmd على Windows.
3. يفتح الموقع مباشرة؛ أزرار Website وAdmin panel ظاهرة أسفل الزاوية للتنقل بين الموقع والأدمن.

لا تحتاج Node.js أو خادماً أو استضافة لتشغيل المعاينة. استخدم Chrome أو Edge. ملفات التشغيل والأنماط مضمّنة داخل index.html؛ أبقِ الصور والفيديوهات بجانبه. الخطوط الخارجية تستفيد من الاتصال بالإنترنت، وبدونه تُستخدم الخطوط البديلة.

لعرض إطار الهاتف أو إعادة الضبط، افتح Preview-tools.html. الموقع نفسه يتكيف مع عرض المتصفح تلقائيًا.

الطلبات والبيانات المعروضة أمثلة وليست طلبات المتجر. طلب جديد من السلة يظهر بالأدمن على نفس المتصفح. التعديلات والنشر محليان ولا تصلان لأي سيرفر. لا يوجد دفع أو إرسال بريد حقيقي.

للتجربة: افتح عطرًا، جرّب كود الخصم التجريبي DEMO10، وأنشئ طلبًا تجريبيًا، ثم افتح الأدمن والطلبات. تغييرات الصور بحد 1 MB؛ رفع الفيديوهات والتصدير وبعض عمليات السيرفر ليست متاحة في هذه المعاينة.

نسخة Demo للعرض فقط؛ النسخة الفعلية تعمل على Cloudflare بخادمها وقاعدة بياناتها.
